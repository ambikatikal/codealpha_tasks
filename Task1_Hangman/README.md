# CodeAlpha Hangman Game 🎮

## 📌 Project Description

This is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time. The player can make a maximum of 6 incorrect guesses before the game ends.

## ✨ Features

* Randomly selects a word from a predefined list
* Allows the player to guess one letter at a time
* Displays correctly guessed letters
* Shows underscores for unguessed letters
* Prevents duplicate guesses
* Validates user input
* Allows a maximum of 6 incorrect guesses
* Displays a winning message when the word is guessed
* Displays the correct word when the player loses

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python hangman.py
```

5. Enter one letter at a time when prompted.

## 🎯 Game Rules

* Guess the hidden word one letter at a time.
* Only one alphabetic character should be entered at a time.
* Duplicate guesses are not counted again.
* The player gets a maximum of 6 incorrect guesses.
* Guess the complete word before reaching 6 incorrect guesses to win.
